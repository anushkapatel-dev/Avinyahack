# Smart Polyhouse Prototype

A Vite + React version of the supplied Smart Polyhouse prototype.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This project can be connected directly to GitHub and deployed with Vercel or another Vite-compatible hosting service.
